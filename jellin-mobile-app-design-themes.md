# Jellin Mobile App - Design System & Theme Variations

## Overview
This document outlines three distinct theme variations for the Jellin mobile app, ensuring compatibility with the website's UX while providing unique emotional experiences for different user preferences.

---

## Base Design System (Compatible with Website)

### Typography (Mobile App)

**Primary Font Family:** Inter (same as website)

**Font Sizes:**
- **Heading 1 (Hero):** 32px / Bold (800)
- **Heading 2 (Section):** 24px / Bold (700)
- **Heading 3 (Card Title):** 18px / Semibold (600)
- **Body Large:** 16px / Regular (400)
- **Body Regular:** 14px / Regular (400)
- **Body Small:** 12px / Regular (400)
- **Caption:** 11px / Regular (400)
- **Button Text:** 16px / Semibold (600)
- **Tab Label:** 13px / Medium (500)

**Line Heights:**
- Headlines: 1.2x font size
- Body text: 1.5x font size
- Captions: 1.4x font size

## Implementation Notes

### Accessibility
- All text must maintain WCAG AA contrast ratio (4.5:1 for normal text, 3:1 for large text)
- Interactive elements must be at least 44x44px
- Color should not be the only means of conveying information

### Animation Guidelines
- Use subtle animations (200-300ms) for state changes
- Gradient transitions should be smooth and performant
- Button press feedback: scale(0.96) with 100ms duration

### Best Practices
1. Use system fonts as fallback: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
2. Test all gradients on both light and dark backgrounds
3. Ensure sufficient contrast for text overlaying gradients
4. Use semantic color tokens in implementation rather than hard-coded hex values
5. Maintain consistency with website branding while optimizing for mobile-first interaction

## Theme Recommendations by Use Case

- **Happy Vibes:** Best for general consumer apps, loyalty programs, casual rewards
- **Lively & Dynamic:** Best for gamified experiences, fitness apps, competitive features
- **Calm & Playful:** Best for premium tier users, wellness-focused brands, sophisticated audiences

All three themes maintain brand consistency with the Jellin website while offering distinct emotional experiences tailored to different user contexts and preferences.
